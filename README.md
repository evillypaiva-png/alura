# 📚 Repositório de Estudos

Um projeto criado para organizar documentos e materiais de estudo em um único lugar.

## 🎯 Objetivo

Facilitar o acesso aos materiais escolares, permitindo organizar conteúdos por matérias.

## 📂 Conteúdos

O projeto pode armazenar:

- Apostilas
- PDFs
- Resumos
- Exercícios
- Trabalhos
- Anotações
- Links úteis

## 💻 Tecnologias

- HTML5
- CSS3

## 🚀 Como executar

1. Baixe ou clone o projeto.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

## 👨‍💻 Autor

Projeto desenvolvido para fins de estudo.
